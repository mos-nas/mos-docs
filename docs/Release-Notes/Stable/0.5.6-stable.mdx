# 0.5.6-stable

:::tip[Download]
Download this release on the [GitHub Releases](https://github.com/mos-nas/mos-releases/releases/tag/0.5.6-stable) page.
:::

:::info[Bugfix Release]
This is a **bugfix release** to address an issue where IPv6 could hang indefinitely on boot. It is **strongly recommended** to upgrade directly to 0.5.6-stable, as this kernel also includes a fix for a DMA issue.
:::

:::warning[IPv6 SLAAC Users]
If you are using IPv6 and want to use SLAAC, please **disable DHCP for IPv6** before upgrading: **Settings → Network Interfaces**. This is not strictly necessary but recommended.
:::

## System

- Recommended Kernel 6.18.42 (includes DMA fix — **strongly recommended to upgrade**)

## Bugfixes

### Networking
- Fix for IPv6 DHCP hanging indefinitely on boot on some machines
- Fix for formatting issue in nut-server init script

### WebUI
- Add SLAAC, DHCP and Static IPv6 settings to WebUI

### Virtual Machines
- Fix a regression issue when editing VMs for disk sizes

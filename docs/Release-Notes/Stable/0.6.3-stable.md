# 0.6.3-stable

:::tip[Download]
Download this release on the [GitHub Releases](https://github.com/mos-nas/mos-releases/releases/tag/0.6.3-stable) page.
:::

:::danger[Important]
It is recommended to immediately upgrade to MOS 0.6.3-stable because this release includes updates and fixes for the following CVE's:

- Remote Code Execution in NGINX (nginx2root) CVE-2026-123007, CVE-2026-123634, CVE-2026-123633, CVE-2026-121810, CVE-2026-113425
- Unauthenticated Notification Socket Access (mos-notify)
:::

## System

- Recommended Kernel 6.18.64
- Update Docker v29.29.10.1
- Update mos-notify 0.5.3
- Docker compose update uses `--remove-orphans` and prunes dangling images

## New Features

- Necessary changes to now support Auto Update
- Introduce information symbol on top bar
- Make sure to display security notice when an important update is available
- Change some notifications to be more specific for security updates
- Introduce Ticket based notification system for mos-notify WebSocket
- Push notifications reduced to warnings and critical messages only
- MOS Hub now properly supports pagination
- Named volumes preserved on stack update
- New clean up buttons for removed templates in Docker settings
- Install to Disk via WebSocket with cancel functionality
- Pull-to-refresh for VMs and LXC containers on mobile
- Improved app bar and UI layout optimizations

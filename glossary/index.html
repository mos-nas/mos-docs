Glossary

Key terms used in MOS and its documentation.

ABCDFHIKLMNOPRSTUVWXZ

A

API Token
A token created under Settings > Network > Token that authenticates requests to the MOS API from outside the WebUI.
Token management
Related terms: MOS API
Appdata
The directory where Docker containers keep their persistent configuration and data. It must live on a storage pool and should be backed up regularly.
Docker Service settings
Related terms: Docker, Pool

B

bcachefs
A copy-on-write filesystem with checksums and optional replication. bcachefs pool support is planned for a future MOS release and is not yet available.
Planned bcachefs support
Related terms: Pool, Scrub
Bond
Combines two or more physical network interfaces into one logical interface for redundancy or throughput. The switch must be configured to match (LACP or static).
Network configuration
Related terms: Bridge
Boot device
The USB stick or internal disk MOS boots from. Persistent system configuration lives in /boot/config on this device.
Create bootable media
Related terms: Diagnostics
Bridge
A virtual network switch that connects virtual machines and containers to the physical LAN. The recommended interface type for most MOS installations.
Network configuration
Related terms: Bond, VLAN, KVM/QEMU, LXC
Btrfs
A copy-on-write Linux filesystem with snapshots and checksums. Can be used as a pool filesystem and is required for snapshot-based LXC backups.
Pool filesystems
Related terms: Snapshot, Scrub, Pool

C

CHAP
Challenge Handshake Authentication Protocol. Used to authenticate an iSCSI initiator against a target.
iSCSI Target
Related terms: iSCSI, IQN

D

Diagnostics
A downloadable .tar.gz archive containing system information, logs and configuration. Attach it when asking for support.
Create a diagnostics file
Related terms: Boot device
Dnsmasq
A lightweight DNS forwarder and DHCP server that MOS can enable for the local network.
Network Services
Related terms: Bridge
Docker
The container runtime MOS uses for applications. It is enabled and configured under Settings > Virtualization > Docker Service.
Docker Service
Related terms: Docker Template, Docker Compose, Appdata, MOS Hub
Docker Compose
A multi-container stack defined in a compose.yaml file. MOS Hub can deploy Compose stacks as a single app.
Compose templates
Related terms: Docker, Docker Template, MOS Hub
Docker Template
A JSON file describing a container (image, ports, volumes, environment). MOS saves one automatically for every container you create.
Start the first container
Related terms: Docker, Docker Compose, MOS Hub

F

Firmware
In MOS, the complete system image including the OS and kernel that is installed on the boot device and updated through Settings > System > Update System.
Update System
Related terms: Update channel, Boot device
FSNavigator
Internal name of the Filebrowser service. The WebUI calls it Filebrowser; the API endpoints use fsnavigator.
Filebrowser
Related terms: WebUI

H

Hub Repository
A GitHub repository in the layout the MOS Hub expects (docker/, compose/, plugins/) that can be added as a template source.
Create your own repository
Related terms: MOS Hub, Docker Template, Docker Compose, Plugin

I

IQN (iSCSI Qualified Name)
The unique identifier of an iSCSI target or initiator. The initiator IQN is generated automatically by MOS.
Target IQN format
Related terms: iSCSI, LUN
iSCSI
A protocol that shares block storage over the network. MOS can export storage as a target and mount remote targets as an initiator.
iSCSI Target
Related terms: IQN, LUN, CHAP

K

KVM/QEMU
The full-virtualization stack used for MOS virtual machines. VMs are enabled under Settings > Virtualization > VM Service.
VM Service
Related terms: VirtIO, OVMF, PCI Passthrough, Bridge

L

LUN (Logical Unit Number)
A block device exported by an iSCSI target. Each LUN is backed by a disk, partition or image file on the MOS server.
LUNs
Related terms: iSCSI, IQN
LXC (Linux Containers)
Lightweight OS-level virtualization that shares the host kernel. Containers are managed on the LXC page and enabled under Settings > Virtualization > LXC Service.
LXC Service
Related terms: Snapshot, Bridge, Docker

M

mergerfs
A union filesystem that combines several disks into one mountpoint. Often combined with SnapRAID.
mergerfs pools
Related terms: SnapRAID, Pool, Virtual Pool
MFA
Multi-factor authentication using a TOTP app in addition to the password. Each account also gets recovery codes for when the app is unavailable.
User profile and MFA
Minimal Free Space
The free-space threshold at which MOS stops writing to a disk and moves on to the next disk in a mergerfs or nonraid pool.
Pool configuration fields
Related terms: Pool, mergerfs, nonraid
MOS API
The REST API used by the WebUI and available for automation. Interactive documentation (Swagger UI) is served at /api-docs/ on the MOS IP.
API overview
Related terms: API Token, Rate limit, WebUI
MOS Hub
MOS app catalog for installing Docker containers, Compose stacks and plugins.
MOS Hub settings
Related terms: Docker Template, Docker Compose, Plugin, Hub Repository

N

Netbird
An open-source mesh VPN based on WireGuard that MOS can enable as an alternative to Tailscale.
Network Services
Related terms: Tailscale
NFS (Network File System)
The file-sharing protocol used to mount MOS shares on Linux and Unix clients.
Network Services
Related terms: Share, SMB
nonraid
A pool type with dedicated parity disks, similar to Unraid. Requires the nonraid driver, which is installed from the MOS Hub.
nonraid pools
Related terms: Parity, Resync, Pool, Plugin
NUT (Network UPS Tools)
The service MOS uses to monitor a UPS and trigger a graceful shutdown when mains power is lost.
NUT configuration
Related terms: UPS, Spindown

O

OVMF
The UEFI firmware used by virtual machines. Required for Windows 11 and modern Linux distributions.
Create the first VM
Related terms: KVM/QEMU, VirtIO

P

Parity
Redundant data stored on one or more parity disks so a failed data disk can be rebuilt. Parity disks hold no usable capacity. Used by SnapRAID and nonraid.
Parity setup
Related terms: nonraid, SnapRAID, RAID, Resync
PCI Passthrough
Giving a virtual machine exclusive access to a physical PCI device such as a GPU or controller. The host cannot use the device while the VM runs.
PCI passthrough
Related terms: KVM/QEMU
Plugin
An installable extension from the MOS Hub. Drivers are distributed as plugins, and some plugins add their own page to the WebUI.
Drivers and plugins
Related terms: MOS Hub, Hub Repository
Pool
One or more disks managed together as a single storage area. MOS supports single, multi, mergerfs, nonraid and bcachefs pools, plus Virtual Pools built from existing paths.
Create a storage pool
Related terms: Share, Virtual Pool, RAID, Parity
PWA (Progressive Web App)
A website that can be installed as an app. MOS Docs can be installed and cached for offline reading.
WebUI overview

R

RAID (Redundant Array of Independent Disks)
Combining several disks into one protected volume. MOS multi pools support RAID 0 (striping, no protection) and RAID 1 (mirroring).
RAID levels
Related terms: Parity, Pool
Rate limit
Protection that caps API requests at 20 per second by default. The defaults are tuned for stability and should not be changed.
API rate limits
Related terms: MOS API
Resync
Rebuilding parity, or rebuilding a replaced data disk from parity. A nonraid pool is usable during the initial resync but not yet protected.
Parity maintenance
Related terms: Parity, nonraid, SnapRAID

S

samba_only
A user role without WebUI access. The account can only authenticate against file shares.
User roles
Related terms: Share, SMB
Scrub
A maintenance task that reads all data and verifies it against stored checksums, repairing from a mirror where possible. Available for btrfs and bcachefs.
Scrub
Related terms: Btrfs, bcachefs, Snapshot
Share
A folder on a pool that is shared over SMB or NFS.
Create the first shares
Related terms: SMB, NFS, Pool, samba_only
SMART
Self-Monitoring, Analysis and Reporting Technology. Disk health data used for warnings and temperature limits.
S.M.A.R.T. settings
Related terms: Spindown
SMB
The Windows file-sharing protocol. MOS provides SMB shares through Samba.
Samba
Related terms: Share, NFS, samba_only
SnapRAID
Parity-based protection for mergerfs pools. It is not a live RAID; parity is updated on a schedule.
SnapRAID parity
Related terms: mergerfs, Parity, Resync
Snapshot
A point-in-time copy of a container or VM disk used for backups and rollback. LXC snapshot backups require btrfs storage; VM snapshots require qcow2 disks.
Backups and snapshots
Related terms: Btrfs, LXC, KVM/QEMU
Spindown
Putting idle disks into standby after a configured number of minutes to save power and reduce noise.
Spindown settings
Related terms: SMART, Pool
Swapfile
A file on disk used as virtual memory when physical RAM is exhausted. Configured under Settings > System Configuration > System.
Swapfile settings
Related terms: Zswap, ZRAM

T

Tailscale
A WireGuard-based mesh VPN that gives remote access to MOS without port forwarding.
Network Services
Related terms: Netbird

U

Update channel
The firmware track MOS follows: alpha (team testing only), beta (pre-release) or stable (recommended for production).
Update System
Related terms: Boot device
UPS (Uninterruptible Power Supply)
A battery backup that keeps the server running during a power outage. MOS monitors it through NUT and can shut down gracefully.
NUT (UPS)
Related terms: NUT, Spindown

V

VirtIO
Paravirtualized disk and network drivers for virtual machines. They offer the best performance and need separate drivers inside Windows guests.
VirtIO drivers
Related terms: KVM/QEMU, OVMF
Virtual Pool
A pool built from existing directory paths (for example /mnt/main and /mnt/media) combined with mergerfs. No dedicated disks and no formatting required.
Virtual Pools
Related terms: mergerfs, Pool
VLAN
A tagged (802.1Q) network segment configured on an interface. A VLAN can carry its own IP or be used only for bridging.
VLAN configuration
Related terms: Bridge, Bond

W

WebUI
The MOS browser interface. It performs no direct system actions; every action goes through the MOS API.
WebUI overview
Related terms: MOS API, FSNavigator

X

XFS
A journaling filesystem recommended for mergerfs and nonraid data disks.
Pool filesystems
Related terms: Pool, mergerfs, nonraid

Z

ZFS
A copy-on-write filesystem with snapshots, checksums and RAID-Z. Available through the OpenZFS Driver plugin and currently CLI only.
ZFS in MOS
Related terms: Plugin, Scrub
ZRAM
A compressed block device in RAM used as compressed swap or as a fast RAM disk.
ZRAM settings
Related terms: Zswap, Swapfile
Zswap
A kernel feature that compresses memory pages in RAM before they are written to swap.
Zswap settings
Related terms: ZRAM, Swapfile

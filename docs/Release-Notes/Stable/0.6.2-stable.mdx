## System

- Recommended Kernel 6.18.60
- Update Docker 29.9.3
- Update QEMU 11.1.3
- Update mos-notify 04.0

## New Features

- Return ZFS pools on pools endpoint
- Change API notifications to support new info priority
- Add notification provider notification level validation
- Create endpoints to delete individual or all Docker templates
- Create endpoints to delete individual or all Compose Stack templates
- Refactor webpush.service.js for code consistency
- Add reboot_pending to plugin installations
- Update VAPID email and improve error handling for web push notifications
- Skip devices which don't support SMART
- Add new keys to show if OS update is available on mos/services endpoint
- Add new key menu_layout to user
- Show external ZFS pools but disable menu
- Add drag and drop for file explorer
- Refactor Docker and Compose create pages
- Refactor notifications and add notification levels
- Add Simplified Chinese (zh) and Traditional Chinese (zh-TW) localization
- Refactor MOS Hub
- Implement pull to refresh functionality
- Add horizontal menu layout prototype
- Translation fixes and terminology standardization

## Bugfixes

- Fix for wrong variable in rollback function
- Refactor Compose icon download routine and fix icon key
- Fix disk UUID handling for non-RAID on replace
- Fix terminals
- Fix webterminal height
- Fix error messages while creating Docker and Compose stacks
- Fix MOS Hub messages
- Fix switch autostart for Compose stacks
